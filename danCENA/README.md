# danCENA

一个可以**自己上传音乐**的单文件 2D 舞蹈舞台。由「舞动实验室 · 当前版（三角色版）」的最后一版改造而来，保留原有编舞、拖拽重力与手机体感，删掉了通过连点解锁的第二个隐藏角色。

直接用浏览器打开 [`index.html`](index.html) 即可，不需要安装、不需要联网。图片、音乐和代码全部在同一个 HTML 文件里。

## 两位舞者

| 角色 | 说明 |
| --- | --- |
| 萌奶 | 银发与缎带 · 幻想舞台 |
| 困困蓝 | 猫咪眼罩 · 慵懒舞步 |

点击右上角「⇄ 切换角色」可以随时换人。切换时会暂停播放，并保留当前音乐位置、动作和节拍设置。

## 自己上传音乐

页面右侧（手机上在下方）新增了「自己上传音乐」卡片：

- **点击**虚线区域或「⬆ 选择音乐」按钮，选择本机的 MP3 / WAV / M4A / OGG 等音频；
- 也可以把音频文件**直接拖进**虚线区域；
- 上传后会立即替换当前曲目，并自动估算 BPM 与对拍位置，舞蹈跟着新音乐走；
- 音乐保存在浏览器的 IndexedDB 中，**下次打开会自动恢复**，不用重复上传；
- 点「↺ 恢复内置音乐」随时换回自带的 `onlyfeelslike.mp3`，同时清除已保存的上传；
- 节拍识别不准时，展开「节拍与对拍微调」，手动调整 BPM 和对拍偏移。

上传文件只保存在这台设备的这个浏览器里，不会写回 HTML，也不会上传到任何服务器。单首上限 60 MB。

## 继承下来的玩法

- 20 多套动作预设：特色串烧、大幅扭腰、双臂上下大摆、风车臂、侧压伸展、中式 / 日式 / 德式组合、柔和组合等；
- 动作幅度 0–200%、动作速度 0.5–2× 独立调节，音乐速度不变；
- 按住角色向上拖：提起、摇摆，松手后带重力与惯性落地；
- 手机体感：倾斜改变重力方向，摇晃产生惯性，可校准中心；
- 播放 / 暂停、重播、拖动进度、空格键播放；
- 切到后台自动暂停。

## 相对「舞动实验室 · 当前版」的改动

1. **彻底删除第二个隐藏角色**：角色数据、三张角色卡改为两张、连点 5 次解锁的隐藏逻辑、隐藏提示与相关样式全部移除；角色索引重新编号，困困蓝的裁切、腰部高度和手臂支点按新编号校准。
2. **新增音乐上传**：独立的「自己上传音乐」卡片、点击 / 拖拽上传、自动节拍识别、IndexedDB 本地持久化、恢复内置音乐、上传状态提示。
3. **品牌改为 danCENA**：标题、页头、舞台角标、favicon、说明文案全部更新；单文件从约 11.9 MB 减到约 9.9 MB（移除了隐藏角色的内嵌图）。
4. 原生音频控件隐藏，播放统一由页面按钮控制；新增文件类型 / 大小校验和出错回退。

## 兼容性与已知限制

- 建议使用较新的 Chrome、Edge、Safari 或 Firefox。手机体感需要 HTTPS 页面或 App 环境，并且需要浏览器授权传感器。
- 上传音乐的持久化依赖 IndexedDB；无痕模式、禁用站点数据或换浏览器后不会保留。
- 自动节拍识别对鼓点清晰的音乐效果最好；识别不准时用「节拍与对拍微调」手动设置。
- 角色是 2D 关节动画，动作经过改编，并非标准体操教学。

## 来源

角色与编舞来自「舞动实验室」项目；困困蓝由插画改编，脚部和关节遮挡处经过 AI 补齐。内置曲目为 `onlyfeelslike.mp3`。
