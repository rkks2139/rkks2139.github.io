1. 最小骨架

每个网页都长这样。结构永远是 head（给机器看）+ body（给人看）两部分：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">          <!-- 告诉浏览器用 UTF-8 解码，否则中文乱码 -->
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>标签页上的标题</title>   <!-- 出现在浏览器标签和搜索结果里 -->
</head>
<body>
    页面内容放这里
</body>
</html>
和 Python 最大的不同：HTML 不是程序，没有变量、没有循环、没有 if。它只是给一段文字「贴标签」，告诉浏览器哪部分是标题、哪部分是一张图。

2. 标签语法（记住这一条就够了）

<标签名 属性="值">内容</标签名>
  ↑           ↑        ↑        ↑
 开始标签    属性     内容    结束标签（比开始多了 / ）
  • 大部分标签成对出现：<p>…</p>、<div>…</div>。
  • 少数「空标签」没有内容，不写结束标签：<img>、<br>、<hr>、<input>、<meta>。
  • 属性写在开始标签里，格式 名字="值"，一个标签可以有多个属性。
  • 尖括号本身要用实体：想显示 < 就写 &lt;，> 写 &gt;，& 写 &amp;。（这就是上面代码块能显示标签的原因）
  • 注释：<!-- 写给人看的话 -->，不会显示在页面上。
  • 不区分大小写，但约定俗成全部小写。
  • 缩进是你的朋友：嵌套关系靠缩进看清楚，跟 Python 一样。

6. 图片与链接

<a href="https://www.python.org" target="_blank">去官网</a>

<img src="photo.jpg" alt="一张猫的照片" width="300">
  • href：链接去哪儿。可以是网址、也可以是同目录的另一个文件（about.html）、还可以是锚点 #section。
  • target="_blank"：新标签页打开。
  • src：图片路径；alt：图挂了或给读屏软件看的文字，一定要写。

7. 表单：接收用户输入

<form>
  <label for="name">名字</label>
  <input id="name" name="name" type="text" placeholder="请输入">

  <select name="lang">
    <option value="py">Python</option>
    <option value="js">JavaScript</option>
  </select>

  <textarea name="msg" rows="3"></textarea>
  <button type="submit">提交</button>
</form>

常见的 input type：text、password、email、number、date、checkbox、radio、file、color、range。
