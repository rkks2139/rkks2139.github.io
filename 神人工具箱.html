03 / QUICK START

三步启动OPEN. ALLOW. PLAY.

所有项目都按“解压 → 浏览器打开 → 点击一次画面”的顺序工作。没有安装向导，也没有账号系统。

  1. 01
    解压到本地

    从 ZIP 解压到任意文件夹。不要在压缩包预览里直接双击，尤其是带 src/ 或 songs/ 的版本。

  2. 02
    用浏览器打开

    双击 HTML，或右键 → 打开方式 → Chrome / Edge。Windows 用户也可以双击 Start-Windows.bat。

  3. 03
    允许音频，必要时全屏

    因为浏览器自动播放限制，第一次需要点击一次画面。音游建议按 F11 或使用页面内全屏按钮。
